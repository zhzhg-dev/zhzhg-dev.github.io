## Brief

Keep David Heckhoff's warm, welcoming, softly rounded studio sensibility. The user likes the approachable miniature-world feeling of Animal Crossing, not a retro operating system or a dark technology showcase. This is Grant's personal website, not only a project catalogue.

## Review of the direction

Warm cream and rounded surfaces are deliberately retained because the user selected them. Distinction comes from Grant's AI/mathematics/teaching context, the Auckland window and working whiteboard—not unrelated abstract ornament, fabricated lifestyle claims or a cloned character. Avoid uniform boxed sections, enormous slogans, rotating paper, autoplay and hover-only functionality.

## Interaction and verification

Scene object notes and whiteboard work with touch and keyboard. Scene colour control is an explicit user action; no sound or autoplay. Respect reduced motion. Check the actual desktop and mobile page in a background browser, alongside builds, regression tests, route checks and deployment confirmation. Do not treat automated tests as proof of visual quality.
